# My Personal Setup

This is my general philosophy for a practical Control D setup.

## Core setup

- One general-purpose profile
- Malware and phishing enabled
- One moderate ad/tracker filter
- One trusted third-party list only
- A small allowlist for real exceptions

## Why this is my default

This keeps protection useful without creating unnecessary maintenance burden.

A large list of exceptions is usually a sign that the base setup is too aggressive or too broad.

## When I increase protection

I move toward a stronger setup only if:

- I understand the trade-offs
- I am okay with more maintenance
- I am testing on a non-critical profile first
- I am actively monitoring false positives

## When I reduce protection

I reduce enforcement when:

- A device is unreliable or highly sensitive to compatibility issues
- A family device is more important than maximum blocking
- The user is not comfortable troubleshooting DNS rules
- The setup is creating too many exceptions

## Main principle

The best DNS profile is usually the one that is the easiest to trust.

If it is reliable, understandable, and easy to maintain, it is probably the right setup.
